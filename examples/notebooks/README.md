# Task-based notebooks

These notebooks are organized by workflow, not by model family.
Use one notebook per task, then swap the model key as needed.

| Notebook | Purpose |
| --- | --- |
| `finetune_lora.ipynb` | Fine-tune with LoRA |
| `finetune_lora_int8.ipynb` | Fine-tune with LoRA + INT8 |
| `evaluate_perplexity.ipynb` | Run perplexity evaluation |

For model keys and variant templates, see `https://xturing.stochastic.ai/overview/supported_models` in the docs.
